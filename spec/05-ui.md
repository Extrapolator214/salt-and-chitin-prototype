# 05 · Interface

Bare bones: flat-coloured polygons, circles, and text. No sprites, no images, no
gradients, no animation except position interpolation of units during a resolve.

## §1 · Layout

```
+--------------------------------------------------------------+
|  HUD BAR   turn · act · resources · hands · hull · seed       |
+-----------------------------------------------+--------------+
|                                               |  HOVER PANEL |
|                  MAP CANVAS                   |  (tile info) |
|                                               +--------------+
|                                               |  ORDER QUEUE |
|                                               |              |
+-----------------------------------------------+--------------+
|  ACTION BAR   [Build] [Buy] [Economy] [Flare] [Assault] [End Turn] |
+--------------------------------------------------------------+
|  LOG   last 6 events                                          |
+--------------------------------------------------------------+
```

The map canvas fills the remaining space and resizes with the window. The right
column is 280 px.

## §2 · Map rendering

One `<canvas>`, 2D context.

### Camera

- Pan: drag with the left mouse button on empty ground, or arrow keys.
- Zoom: mouse wheel, 6 discrete levels from hex size 3 px to 24 px.
- At hex size ≤ 5 px, skip outlines and draw filled hexes only.
- Cull to the visible rect: convert the viewport corners to axial bounds and
  iterate only that range. Never iterate all 7651 tiles per frame.

### Terrain colours

| terrain | fill |
|---|---|
| forest | `#2f5d3a` |
| canopy | `#1e4029` |
| scrub | `#6d7a48` |
| stone | `#7a7a72` |
| road | `#b9a582` |
| sand | `#d9c48f` |
| salt | `#e8e6dd` |
| fresh water | `#3c6d8f` |
| cliff | `#5a5048` |
| salt water | `#25506e` |

Cleared tiles draw as `road`. A 1 px darker outline at hex size > 5 px.

### Overlays

| thing | drawing |
|---|---|
| **base** | white heptagon over the 7 base tiles, hull bar above it |
| **tower** | coloured triangle, size by tier; the tier number in white at hex size ≥ 12 |
| **unmanned tower** | the same triangle, 40% opacity, hollow |
| **building** | grey square over its footprint, first letter of its name |
| **spawner** | red hexagon over its footprint, star pips above it |
| **cohort** | red outline over its occupied tiles, translucent red fill, unit count in the centre — or `?` if it stands on forest or canopy |
| **unit** (resolve only) | 3 px circle; grub pale, shell dark, elite double size with a ring |
| **tower range** | on hover or selection, a thin ring at the tower's range |
| **exclusion zone** | on hover of a spawner, a dashed ring at radius 7 |
| **cache** | small gold diamond |
| **spring / officer site / wreck** | small cyan / white / brown diamond |
| **assault march** | a dashed line from base to target with the turns remaining |

### Fire, during a resolve

A 1 px line from tower to target, drawn for 2 frames per damage application.
Nothing else.

## §3 · The hover panel

Updates on every `mousemove` over the canvas. Always shows, for the tile under
the cursor:

```
(q, r)                     distance from base: 23

FOREST
  clearable      yes — 3 wood
  buildable      yes
  passable       yes
  advance        3.0× slow
  targetable     NO while virgin

feature          treasure cache (undug)
occupant         —
```

If the tile carries a tower, building, spawner or base, the panel adds a block
for it:

| occupant | extra lines |
|---|---|
| tower | tower name · tier · power · range · manned by · fitted item tier |
| building | name · what it owns · manning · unmanned yes/no · production this turn |
| spawner | kind · stars · mode · turns until release · units accumulating |
| base | hull · hold contents · ship dps and range |

If a cohort occupies the tile: `cohort · N units · arriving in T turns` — with `N`
replaced by `?` while it stands on cover.

The panel never blocks or requires a click.

## §4 · HUD bar

One line, always visible:

```
Turn 84 / 300   ACT I     wood 412  stone 190  iron 24  gold 300
hands 15  ·  shovels 9 (60%)  ·  hull 100/100     seed 20260816
```

- **shovels** is the labour readout and is bolded when below 20%.
- Hull turns amber below 60, red below 30.
- Clicking `hands` opens the crew modal.

## §5 · Modals

All menus are modals: a centred panel over a dim backdrop, `Esc` and a close
button dismiss. Only one at a time; opening a second replaces the first. No
nesting.

| modal | opened by | contents |
|---|---|---|
| **Build tower** | Build button, or clicking an empty buildable tile | the eight towers as rows: name, range, shape, cost, a Build button. Disabled rows show why. |
| **Tower** | clicking a tower | tier, power, range, manning, fitted item · buttons: fit an item (lists eligible inventory tiers), man/unman, evolve (lists legal partners), disassemble |
| **Inventory** | Buy button | item tiers as a row of counts · buy (8 gold) · craft (6 iron, needs a Workshop) · merge (pairs of equal tier) · hold usage `3 / 5` |
| **Economy** | Economy button | the ten buildings as rows: name, tiles, effect, cost, Build. Built ones show manning and an Unman (50 gold) button. |
| **Crew** | HUD hands, or the Crew button | every hand and officer as a row: who, current task, target. Reassign by picking a new task. Shows travel turns for a move. |
| **Flare** | Flare button | cost, hands brought, turns to land, flares used this act, Fire button |
| **Assault** | Assault button | target spawner list with: road path yes/no, leader dropdown (3 officers or nobody), success %, hands required, Schedule button |
| **Assault result** | automatically, on resolution | outcome, a three-line narration, what changed |
| **Turn summary** | automatically, on End Turn if anything happened | tiles cleared, resources gained, buildings finished, spawner state changes, cohort arrivals |
| **Combat** | automatically, when a cohort reaches a road | see §6 |
| **End of run** | automatically | outcome and the run statistics, New run button |

Every modal is plain HTML: a heading, a table, buttons. No styling beyond
borders, padding and the two backdrop colours.

## §6 · The combat modal

The resolve is watched, not played. It does **not** cover the map — it is a
narrow strip along the bottom of the screen while the map keeps rendering.

```
CONTACT — entry at (18, -31)          [1×] [3×] [skip]
cohort: 16 units (11 grub, 5 shell)     killed 4     leaked 0
elapsed 6.3 s
```

Buttons set the tick multiplier. `skip` jumps to the end and applies the result.

## §7 · The order queue panel

A list of pending orders with a `×` to revoke each:

```
QUEUE
  clear from (4,-9)          × 
  build Swivel Gun at (2,-7) ×
  fire flare                 ×
```

Ending the turn while the queue is non-empty shows the turn-summary modal after
resolve, not a confirmation before it.

## §8 · The log

The last 6 events, newest at the bottom, plain text:

```
t83  cleared 9 tiles (+21 wood, +5 stone)
t84  the hive gains a star (3)
t84  a cohort of 16 reaches your road at (18,-31)
t84  contact: 12 killed, 4 leaked, hull 100 -> 84
```

## §9 · Input summary

| input | effect |
|---|---|
| hover a tile | the hover panel |
| left-click empty buildable tile | Build tower modal, anchored there |
| left-click a tower / building / spawner | its modal |
| right-click / shift-click a tile | assign the next idle hand to clear from there |
| drag | pan |
| wheel | zoom |
| `Space` | End Turn |
| `Esc` | close the modal |
| `1` `2` `3` | resolve speed, during combat |

# 05 · Interface

Bare bones: flat-coloured polygons, circles, and text. No sprites, no images, no
gradients, no animation except position interpolation of units during a resolve.

## §1 · Layout

```
+--------------------------------------------------------------+
|  HUD BAR   turn · act · resources · hands · hull · seed       |
+-----------------------------------------------+--------------+
|                                               |  HOVER PANEL |
|                  MAP CANVAS                   |  (tile info) |
|                                               +--------------+
|                                               |  ORDER QUEUE |
|                                               |              |
+-----------------------------------------------+--------------+
|  ACTION BAR   [Build] [Buy] [Economy] [Flare] [Assault] [End Turn] |
+--------------------------------------------------------------+
|  LOG   last 6 events                                          |
+--------------------------------------------------------------+
```

The map canvas fills the remaining space and resizes with the window. The right
column is 280 px.

## §2 · Map rendering

One `<canvas>`, 2D context.

### Camera

- Pan: drag with the left mouse button on empty ground, or arrow keys.
- Zoom: mouse wheel, 6 discrete levels from hex size 3 px to 24 px.
- At hex size ≤ 5 px, skip outlines and draw filled hexes only.
- Cull to the visible rect: convert the viewport corners to axial bounds and
  iterate only that range. Never iterate all 7651 tiles per frame.

|---|---|
| forest | `#2f5d3a` |
| canopy | `#1e4029` |
| scrub | `#6d7a48` |
| stone | `#7a7a72` |
| road | `#b9a582` |

Cleared tiles draw as `road`. A 1 px darker outline at hex size > 5 px.

### Overlays

| thing | drawing |
|---|---|
| **base** | white heptagon over the 7 base tiles, hull bar above it |
| **tower** | its yard filled in the gun's own colour over all 1–3 tiles, a coloured triangle on the anchor sized by tier, the tier number in white at hex size ≥ 12 |
| **unmanned tower** | the same, yard faint and the triangle 40% opacity, hollow |
| **building** | grey square over its footprint, first letter of its name |
| **spawner** | red hexagon over its footprint, star pips above it |
| **cohort** | red outline over its occupied tiles, translucent red fill, unit count in the centre — or `?` if it stands on forest or canopy |
| **unit** (resolve only) | 3 px circle; grub pale, shell dark, elite double size with a ring |
| **unit health** (resolve only) | a bar over every living unit at hex size ≥ 8: green above 60%, amber above 30%, red below; a shield-bearer's plate as a blue band above the bar |
| **tower range** | on hover or selection, a thin ring at the tower's range |
| **exclusion zone** | on hover of a spawner, a dashed ring at radius 7 |
| **Bunkhouse reach** | on hover of a standing Bunkhouse, the same shaded blob and ringed yards the cursor carried while it was being placed — every hex within `BUNKHOUSE_RADIUS` of any of its tiles, with the yards it takes in outlined inside. One drawing shared with the placement outline, so the promise and the account of it cannot drift apart |
| **placement outline** | the fixed shape under the cursor, green or red per tile, with the refusal above it. A tower carries its range ring and its tier; a **Bunkhouse carries its reach** — every hex within `BUNKHOUSE_RADIUS` of any tile of the plot, shaded, with the yards it would take in ringed inside it and counted on the label |
| **cache** | small gold diamond |
| **spring / officer site / wreck** | small cyan / white / brown diamond |
| **a point of interest that can be worked today** | the marker glitters: a scatter of small sparks in its own colour, each twinkling on its own phase. Only for sites that are unworked, have an action, and stand on open ground — the three the sim asks before it will take the order. A chest under standing forest sits still |
| **ground that could be worked** | at hex size ≥ 5, **one outline around the whole offer**: every tile that could be queued for clearing right now — clearable ground on or beside what the crew can reach — together with every unbridged fresh-water tile beside it. Interior edges are not drawn, so what is on the map is the shape of the offer and not a box per tile; each stretch of the border is coloured by the tile behind it, sand for ground and blue for water. A glimmer travels along it, one wave crossing the map at about a hex a second. It is the quietest mark on the map and everything the player has already decided is drawn over it. Hidden while a reel plays, while a shape is being placed, and outside the player phase |
| **assault march** | a dashed line from base to target with the turns remaining |

### Fire, during a resolve

Every gun throws a **round** on its own cadence (`SHOT_INTERVAL`, by the tower's
`rate`) at the spot its target stood on when the trigger went. The round is a
dot in the gun's colour with a short tail behind it, travelling at
`PROJECTILE_SPEED`, and it leaves a ring flash where it lands — wider for a
blast gun. Rounds carry no damage: the damage is the rate, applied every tick as
it always was. A line from tower to target is drawn nowhere.

## §3 · The hover panel

Updates on every `mousemove` over the canvas. Always shows, for the tile under
the cursor:

```
(q, r)                     distance from base: 23

FOREST
  clearable      yes — 3 wood
  buildable      yes
  passable       yes
  advance        3.0× slow
  targetable     NO while virgin

feature          treasure cache (undug)
occupant         —
```

If the tile carries a tower, building, spawner or base, the panel adds a block
for it:

| occupant | extra lines |
|---|---|
| tower | tower name · tier · power · range · manned by · fitted item tier |
| building | name · what it owns · manning · unmanned yes/no · production this turn · for a Bunkhouse, its reach and the yards it takes in, named and counted (its own included, marked) |
| spawner | kind · stars · mode · turns until release · units accumulating |
| base | hull · hold contents · ship dps and range |

If a cohort occupies the tile: `cohort · N units · arriving in T turns` — with `N`
replaced by `?` while it stands on cover.

The panel never blocks or requires a click.

## §4 · HUD bar

One line, always visible:

```
Turn 84 / 300   ACT I     wood 412  stone 190  iron 24  gold 300
hands 15  ·  shovels 9 (60%)  ·  hull 100/100     seed 20260816
```

- **shovels** is the labour readout and is bolded when below 20%.
- Hull turns amber below 60, red below 30.
- Clicking `hands` opens the crew modal.

## §5 · Modals

All menus are modals: a centred panel over a dim backdrop, `Esc` and a close
button dismiss. Only one at a time; opening a second replaces the first. No
nesting.

| modal | opened by | contents |
|---|---|---|
| **Dev menu** | the Dev menu button in the bar, beside Restart map | cheats, for reaching a part of a run without playing to it: *no distance limit for units* (a walk of any length costs no turns) and *units walk through unopened ground* (standing wood and scrub crossed as if open — never cliff, unbridged water, sea or boulders, and the cohorts' own approach is untouched), plus **Add 100** of wood, stone, iron or gold. Everything takes effect on the spot, is written into the saved run, and is logged. The flags live in the run (`state.dev`), so a reload comes back cheating the same way; the grants are not counted in the end-of-run stats, which report what the island gave up |
| **Restart this map** | the Restart map button in the bar | the seed again from turn 1 — the same ground, the same spawners, the same chests. Asks first: the run on screen and its saved copy are both lost. |
| **Towers** | the Towers button in the bar | the eight towers as rows: name, range, tiles, fire, fitting held, the tier it would build at by default, cost, and **one Build button per tier held** — each picks the gun up at that tier to be placed. Disabled rows show why — the price and the hold only, since no tile has been chosen yet. Below, every tower standing: where, tier, power, manning, Open and locate. |
| **Tower** | clicking a tower | tier, power, range, manning, fitted item · buttons: fit an item (lists eligible inventory tiers), man/unman, evolve (lists legal partners), disassemble |
| **Inventory** | Buy button | two shelves, one per house: the Workshop's ironwork (craft, 6 iron) and the Peculiar Merchant's wares (buy, 8 gold) · counts held per tier · merge (pairs of equal tier) · hold usage `3 / 5` |
| **Dock counter** | the Trading Dock's panel | wood, stone and iron bought or sold in any amount, priced per lot · an amount box and an `all` button per good · staged and then confirmed, because it moves the stores on the spot rather than queuing an order |
| **Economy** | Economy button | the ten buildings as rows: name, tiles, effect, cost, Build. Built ones show manning and an Unman (50 gold) button. |
| **Crew** | HUD hands, or the Crew button | every hand and officer as a row: who, current task, target. Reassign by picking a new task. Shows travel turns for a move. Carries the switch that turns the idle reminder back on, when it is off. |
| **Nobody has told them what to do** | End Turn, with crew standing about | who is idle · *End the turn anyway* · *Go back* · *End it, and stop reminding me*, which ends the turn and turns the box off for good. That is a setting, not a decision about the turn: it is kept outside the run, so it survives a reload and a new run, and the crew panel is where it goes back on. |
| **Flare** | Flare button | cost, hands brought, turns to land, flares used this act, Fire button |
| **Assault** | Assault button | target spawner list with: road path yes/no, leader dropdown (3 officers or nobody), success %, hands required, Schedule button |
| **Assault result** | automatically, on resolution | outcome, a three-line narration, what changed |
| **Turn summary** | automatically, on End Turn if anything happened | tiles cleared, resources gained, buildings finished, spawner state changes, cohort arrivals |
| **Combat** | automatically, when a cohort reaches a road | see §6 |
| **End of run** | automatically | outcome and the run statistics, New run button |

Every modal is plain HTML: a heading, a table, buttons. No styling beyond
borders, padding and the two backdrop colours.

## §6 · The combat modal

The resolve is watched, not played. It does **not** cover the map — it is a
narrow strip across the top of the map, under the top bar and stopping at the
side column, while the map keeps rendering.

```
CONTACT — entry at (18, -31)                            [1×] [3×]
cohort: 16 units (11 grub, 5 shell)     killed 4     leaked 0
elapsed 6.3 s
```

The bar carries the two speeds and nothing else, the one in force lit. Pace is
all it offers: the control that ends the thing you are watching does not belong
under the pointer beside them. Skipping — jump to the end and apply the result —
is the `3` key, and stays on the keyboard.

**Nothing else is live while a contact plays.** The map takes no clicks — no
tile panel, no shift-click, no right-click — and every button on the action row
is disabled, the same as during a reel: the queue has already been applied and
the ground has already moved, so an order given here would be given to a state
the player cannot see the whole of. Panning, zooming and hovering stay live,
because looking is not touching and a fight is when the camera is most wanted.

**The pace is remembered.** It is a standing choice about watching, not a
decision about one cohort: a fight set to 3× opens the next contact at 3×, and
the run after that, since it is kept with the settings rather than with the run.
Skipping is not remembered — it is done to the fight in front of you.

The buttons are markup that stands, not markup rewritten with the numbers: the
strip is written every frame, and a button replaced between the press and the
release never gets its click.

## §7 · The order queue panel

A list of pending orders with a `×` to revoke each:

```
QUEUE
  clear from (4,-9)          × 
  build Swivel Gun at (2,-7) ×
  fire flare                 ×
```

Ending the turn while the queue is non-empty shows the turn-summary modal after
resolve, not a confirmation before it.

## §8 · The log

The last 6 events, newest at the bottom, plain text:

```
t83  cleared 9 tiles (+21 wood, +5 stone)
t84  the hive gains a star (3)
t84  a cohort of 16 reaches your road at (18,-31)
t84  contact: 12 killed, 4 leaked, hull 100 -> 84
```

## §9 · Input summary

| input | effect |
|---|---|
| hover a tile | the hover panel |
| left-click empty ground | the tile's own panel — what can be cut or worked there, and where to pick a structure from |
| left-click with a tower or yard picked up | place it there |
| left-click a tower / building / spawner | its modal |
| right-click / shift-click a tile | assign the next idle hand to clear from there |
| drag | pan |
| wheel | zoom |
| `Space` | End Turn |
| `Esc` | close the modal |
| `1` `2` `3` | resolve speed, during combat |
